# CLASSROOM DRAW

授業中の出席番号抽選を、見やすく・盛り上がる演出で行う静的Webアプリです。

## 主な機能
- 通常抽選
- サバイバル抽選
- MISSION抽選
- 欠席番号除外
- 指名済み優先制御
- 指名履歴
- 1回戻す / 当日履歴リセット
- ブラウザ内保存
- 効果音
- LUCKY SAFE
- manual.html
