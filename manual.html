CLASSROOM DRAW

使い方

アプリへ戻る

このアプリは何をする？

授業中に出席番号を抽選して、発表・音読・回答などの指名を楽しく行うアプリです。名前は登録せず、出席番号だけで使えます。

まずこれだけ

  1. 「設定を開く」からクラス名と最大出席番号を入力し、「このクラスを保存」を押します。
  2. 欠席者がいれば「欠席を設定」で番号をタップします。
  3. SLOT / ROULETTE / SURVIVAL / MISSION を選び、「DRAW!」を押します。

4つの抽選モード

SLOT：番号が高速で切り替わり、少しずつ減速して1人決まります。

ROULETTE：カラフルなルーレットが回転し、停止して番号を発表します。

SURVIVAL：候補が段階的に減り、FINAL 3から最後の1人を選びます。

MISSION：番号決定後に「英文を音読」「理由を言う」などのミッションも抽選します。

クラス保存

複数クラスを保存できます。「＋ 新しいクラス」で別クラスを作り、クラス名・最大出席番号・欠席番号・指名履歴・設定をクラスごとに保持します。

上部のクラス選択から、保存したクラスをすぐ切り替えられます。

指名したあとの「回し方」も抽選

最初の1人が決まると「回し方を抽選」ボタンが表示されます。進み方・横方向・縦方向を組み合わせた8パターンから1つをランダムに選びます。

公平に当てる

「一度当たった人を次回以降除外」をONにすると、まだ指名されていない番号を優先します。全員が一巡したあとは再び全員が候補になります。欠席番号は常に除外されます。

データ

クラス名、最大出席番号、欠席番号、指名履歴、MISSION候補などは、このブラウザのlocalStorageに保存されます。別端末には自動同期されません。生徒名などの個人情報は登録しない設計です。

What does this app do?

CLASSROOM DRAW randomly picks student numbers for speaking, reading aloud, answering questions, and other classroom activities. It uses student numbers only, so student names do not need to be stored.

Quick start

  1. Open Teacher controls, enter the class name and highest student number, then tap Save this class.
  2. If anyone is absent, tap Set absences and select their numbers.
  3. Choose SLOT, ROULETTE, SURVIVAL, or MISSION, then press DRAW!

Four draw modes

SLOT: Numbers change rapidly and slow down until one student is picked.

ROULETTE: A colorful wheel spins and stops on the selected number.

SURVIVAL: The pool gets smaller in stages until one student remains from the FINAL 3.

MISSION: After a number is picked, the app also chooses a classroom mission.

Save multiple classes

You can keep separate class names, highest student numbers, absences, pick history, and settings for multiple classes. Use + New class to add another class and the class menu at the top to switch between them.

Draw the next order

After the first student is selected, Draw next order randomly chooses how to continue around the classroom: across rows or down columns, window-to-hallway or hallway-to-window, and front-to-back or back-to-front.

Keep picks fair

Turn on Exclude students already picked to prioritize numbers that have not yet been selected. After everyone has been picked once, the full eligible pool becomes available again. Absent numbers are always excluded.

Data

Class settings, absences, pick history, and MISSION options are stored in this browser using localStorage. They do not automatically sync to another device. The app is designed not to store student names.
